1. 用户名必须符合后端注册接口当前的校验规则；若提示“用户名已存在”，在末尾加数字，例如 `earth_test01a`。

3. 这些账号注册完成后，可在 Apifox 登录接口中分别获取 JWT，用于测试“用户不能删除他人记录”等权限场景。
4. 项目演示结束后，如服务器对外开放过，建议删除这些测试账号和测试数据。
