# 华为云服务器启停与重新连接指南

本文适用于 Earth Online 当前的华为云部署方案：

- ECS：Ubuntu 22.04，按需计费；
- 项目目录：`/opt/earth-online`；
- MySQL、MinIO、Spring Boot：Docker Compose 管理；
- Vue：Nginx 提供静态文件；
- 公网入口：弹性公网 IP（EIP）的 80 端口；
- SSH：密钥对登录。

## 1. 先理解“关机”“释放 EIP”和“删除”的区别

| 操作 | 项目数据 | 公网 IP | 主要计费影响 | 下次能否恢复 |
| --- | --- | --- | --- | --- |
| 关闭网页或 SSH 窗口 | 保留 | 保留 | ECS 仍在运行并计费 | 可以，但没有省计算费用 |
| 停止 Docker 容器 | 保留 | 保留 | ECS 仍在运行并计费 | 可以 |
| ECS 关机 | 保留在系统盘 | 如果仍绑定则不变 | 普通按需 ECS 的 CPU、内存停止计费；系统盘等资源继续计费 | 可以 |
| 解绑但不释放 EIP | 保留 | IP 被保留 | 仍可能产生 EIP 保有费用 | 可以重新绑定原 IP |
| 解绑并释放 EIP | 保留 | 原 IP 失效 | 停止该 EIP 后续费用 | 可以，但下次会获得新 IP |
| 删除 ECS/系统盘 | 可能永久丢失 | 可能随实例释放 | 对应资源停止计费 | 不能直接恢复 |

如果只是暂停项目，不要点击“删除 ECS”，也不要删除系统盘。

## 2. 推荐的省钱暂停方式

总展示时间只有约 30 小时，推荐：

```text
停止项目容器
→ 在华为云控制台关闭 ECS
→ 解绑并释放 EIP
→ 保留 ECS 和系统盘
```

这样 MySQL 和 MinIO 数据仍保存在系统盘中，但下次重新购买 EIP 后，公网 IP 会改变。

## 3. 暂停前检查和停止项目

### 3.1 登录服务器

在 Windows PowerShell 执行：

```powershell
$keyPath = "$env:USERPROFILE\.ssh\earth-online-demo-key.pem"
ssh -i $keyPath root@当前公网IP
```

### 3.2 检查容器

部署完成后，在服务器执行：

```bash
cd /opt/earth-online/deploy
docker compose ps
```

### 3.3 平稳停止容器

```bash
docker compose stop
```

该命令只停止容器，不删除容器、MySQL数据和MinIO图片。

不要执行：

```bash
docker compose down -v
```

`-v`可能删除Docker卷。在没有确认备份前也不要删除`/opt/earth-online/data`。

### 3.4 确保磁盘写入完成

```bash
sync
```

然后输入：

```bash
exit
```

退出SSH。关闭SSH窗口本身不会关闭云服务器。

## 4. 在华为云控制台关闭 ECS

1. 登录华为云控制台；
2. 进入“弹性云服务器 ECS”；
3. 选择区域“中国-香港”；
4. 找到`earth-online`；
5. 选中实例；
6. 点击“关机”；
7. 等待状态变成“关机”。

必须在控制台确认状态已经变成“关机”。只关闭浏览器、PowerShell或Docker不会停止ECS计算费用。

## 5. 是否释放公网 IP

### 方案 A：保留固定 IP

让 EIP 继续绑定在已关机的 ECS 上。

优点：

- 下次开机后访问地址不变；
- SSH命令和项目公网配置不用修改。

缺点：

- 香港区域的 EIP 可能继续产生费用；
- 不适合当前约 50 元的小预算。

### 方案 B：释放 EIP（当前推荐）

1. 进入 ECS 详情；
2. 找到“弹性公网 IP”；
3. 点击“解绑”；
4. 进入“弹性公网 IP EIP”控制台；
5. 找到刚解绑的 EIP；
6. 确认没有绑定其他资源；
7. 点击“释放”。

注意：

- “解绑”不等于“释放”；
- 只解绑不释放仍可能收费；
- 释放后原公网IP通常不能找回；
- 下次网站地址会变化；
- 不要删除ECS和系统盘。

## 6. 下次重新开始服务器

### 6.1 启动 ECS

1. 登录华为云控制台；
2. 进入“弹性云服务器 ECS”；
3. 切换到“中国-香港”；
4. 找到`earth-online`；
5. 点击“开机”；
6. 等待状态变成“运行中”。

普通按需实例重新开机时，偶尔可能遇到资源暂时不足。答辩或演示前建议提前 20～30 分钟启动。

### 6.2 重新购买并绑定 EIP

如果上次释放了 EIP：

1. 进入“弹性公网 IP EIP”；
2. 购买新的按需 EIP；
3. 线路选择“全动态 BGP”；
4. 公网计费选择“按流量计费”；
5. 带宽上限选择`5 Mbit/s`；
6. 将新 EIP 绑定到`earth-online`；
7. 记录新的完整公网 IPv4 地址。

安全组仍然关联在 ECS 上，一般不需要重新创建。确认入方向仍有：

```text
TCP 22  你的公网IP/32（部署期间可临时放宽）
TCP 80  0.0.0.0/0
```

不要开放`3306`、`8080`、`9000`和`9001`。

## 7. 使用新 IP 重新 SSH 登录

在本地 PowerShell 执行：

```powershell
$keyPath = "$env:USERPROFILE\.ssh\earth-online-demo-key.pem"
$serverIp = "新的弹性公网IP"
ssh -i $keyPath "root@$serverIp"
```

第一次连接这个新 IP 时可能出现主机指纹提示，确认 IP 是刚绑定给自己 ECS 的地址后，输入：

```text
yes
```

如果22端口连接失败，检查：

- ECS是否已进入“运行中”；
- 新EIP是否已经绑定；
- 安全组22端口来源是否包含当前电脑公网IP；
- SSH服务是否完成启动。

## 8. IP变化后修改项目配置

Earth Online前端使用相对路径`/api`和`/ws`，Nginx配置也不写死公网IP，因此前端文件和Nginx代理通常不需要修改。

但MinIO预签名图片地址需要知道当前公网来源。登录服务器后执行：

```bash
cd /opt/earth-online
nano .env
```

找到：

```text
PUBLIC_ORIGIN=http://旧公网IP
```

改成：

```text
PUBLIC_ORIGIN=http://新公网IP
```

保存Nano：

```text
Ctrl+O
Enter
Ctrl+X
```

不要在聊天、截图或Git中公开`.env`里的数据库密码、JWT密钥、MinIO密钥和DeepSeek Key。

## 9. 重新启动项目

```bash
cd /opt/earth-online/deploy
docker compose --env-file ../.env up -d
```

因为`PUBLIC_ORIGIN`可能发生变化，建议确保后端容器重新创建并读取新环境变量：

```bash
docker compose --env-file ../.env up -d --force-recreate backend
```

检查容器：

```bash
docker compose --env-file ../.env ps
```

检查后端：

```bash
curl http://127.0.0.1:8080/api/health
```

检查Nginx：

```bash
systemctl is-active nginx
```

如果Nginx没有运行：

```bash
systemctl start nginx
```

最后在浏览器访问：

```text
http://新公网IP
```

## 11. 常见问题

### 关机再开机，私有IP会变化吗？

同一ECS、网卡和VPC保留时，私有IP一般保持不变。但外部用户访问使用的是EIP，不是`192.168.x.x`私有IP。

### 关机再开机，公网IP一定变化吗？

不一定。EIP始终绑定且没有释放时通常不变；只有释放旧EIP并重新申请时，才会获得新的公网IP。

### 公网IP变化后，数据库数据会丢失吗？

不会。公网IP只负责网络访问，MySQL和MinIO数据保存在系统盘目录中。

### 为什么不能只关闭PowerShell？

PowerShell只是远程操作窗口。关闭SSH连接后，ECS、Docker和Nginx仍然运行，费用也继续产生。

### 为什么不能只执行`docker compose stop`？

它只停止项目容器，ECS仍然开机，CPU和内存仍然计费。需要暂停计费时还要在华为云控制台关机。

### 一个月结束后怎样彻底停止费用？

先备份MySQL和MinIO数据，再删除ECS、系统盘、EIP以及不再需要的备份资源。仅关机不能停止系统盘等资源费用。

## 12. 最短操作速查

暂停：

```text
SSH执行 docker compose stop
→ sync
→ exit
→ 华为云控制台关机
→ 解绑并释放EIP
```

恢复：

```text
华为云控制台开机
→ 购买并绑定新EIP
→ SSH连接新IP
→ 修改/opt/earth-online/.env中的PUBLIC_ORIGIN
→ docker compose up -d
→ 浏览器访问新IP
```
