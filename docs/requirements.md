# 项目需求文档

## 项目名称
Earth Online - 地球在线

## 项目简介
一个展示地球实时信息与个人时间轴的 Web 全栈应用。

## 核心功能

### 已实现（Vue 前端）
- 用户登录/注册
- 个人主页（头像、姓名、签名）
- 时间轴（个人事件记录）
- 时间胶囊（定时发送消息）
- 年度回顾
- 成就系统
- 新闻动态（地球热点事件）
- 数据统计面板

### 计划开发（后端 + AI）
- [ ] 用户认证系统（JWT）
- [ ] 数据库持久化（Prisma + MySQL/PostgreSQL）
- [ ] 新闻 API 服务
- [ ] AI 内容生成（心情分析/年度总结）
- [ ] 文件上传（头像图片）

### 未来规划（移动端）
